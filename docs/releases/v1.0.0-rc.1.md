# 1.0.0-rc.1 — migration and diagnostic release candidate

## Delivered

- Legacy CPT, CCT, preset and Elementor inventory remains read-only until a
  checksum-bound prepare/confirm operation creates a draft.
- Shadow comparison covers counts, status distributions, data, normalized
  Elementor HTML and a bounded query plan.
- Impact Maps resolve concrete pages, templates, Toolkit widgets, fields,
  records, adapters and backup revisions without substring matching.
- Flight Recorder events are ordered, timed and redacted before persistence.
- QA scenarios replay Collection or migration evidence, and handoff notes are
  generated only from observed diagnostics.
- Four non-distributed sufficiency fixtures compile real-estate, clinic,
  delivery and ecommerce capabilities from the same primitives.
- The release ZIP is deterministic and excludes tests, source assets, build
  tools, dependencies and repository internals.
- Non-transactional CPT/CCT preparation is fenced by durable storage claims;
  the same confirmed `applying` change set can resume idempotently after an
  interrupted run, while foreign ownership remains blocked.
- Extension version, capability and health metadata is snapshotted into
  published contracts and revalidated before runtime execution.
- Pending uploads, relation pickers, exact CPT multivalue filters, typed
  taxonomy projection and Explain Why evidence have focused crash/security
  contracts and live WordPress verification.

## Local pilot

- CPT `__imoveis`: one record, verified draft, runtime not switched.
- CCT `projects`: six records, verified draft, runtime not switched.
- Elementor documents `301`, `340` and `479`: verified drafts with revisions
  retained as backup evidence, runtime not switched.
- Five saved migration scenarios pass fresh replay.

## Open promotion gates

- WooCommerce is not installed, so the live Woo adapter canary is open.
- Destructive field/storage transformations remain fail-closed until the
  copy/transform/count/checksum/switch engine is implemented and proven.
- Virtual Routes currently support literal paths only; parameterized per-item
  routes remain an open capability gate.
- Shadow comparison proves the compiled projection against legacy evidence; it
  is not yet an independent dual-runtime cutover proof.
- WordPress/PHP/Elementor target variants outside the observed local runtime
  still need their live matrix canaries.
- Guilherme must approve the map, inspector, Elementor workflow, frontend forms
  and responsive interaction in a real browser.
- No Git tag, push or public pull request is authorized by this RC preparation.
