# V0.9.0 — Elementor and Woo bridge

Status: mechanically verified; visual approval, tag and remote publication are
intentionally pending.

## Product outcome

V0.9 connects published Blueprint contracts to Elementor without turning the
widget panel into a second schema, query or workflow builder.

- Elementor Free receives five connector widgets for fields, Collections,
  filters, Entry Surfaces and actions.
- Widget controls use stable contract IDs and expose only placement or
  presentation decisions relevant to that connector.
- Elementor Pro receives optional typed Dynamic Tags backed by one value
  resolver and filtered to compatible fields in the known entity context.
- Collection presentations use existing Elementor documents through public
  Core managers. Template creation is explicit and produces a draft; reading a
  template never writes post metadata.
- The former direct dependency on internal Elementor Pro Loop classes is
  removed. A bounded public-manager canary reports compatibility instead.
- WooCommerce exposes product Field Contracts and provider/Entry capabilities
  through Woo query and CRUD APIs. It remains the authority for commerce data
  and all transactional flows stay out of Toolkit Core.
- Filter and Collection connectors target each other by published Collection
  UUID, including automatic or explicit-submit apply modes.

## Runtime facts on the verification workstation

- WordPress 6.9.4
- PHP 8.3.31
- Elementor 4.0.8
- Elementor Pro-compatible runtime 4.0.4.2
- WooCommerce absent; the adapter correctly reports unhealthy while keeping its
  schema visible for Blueprint design and testing

The missing WooCommerce runtime is not treated as an acceptance pass for live
Woo interaction. The adapter has unit and contract coverage, while an installed
Woo runtime remains part of the Wave 7 compatibility matrix.

## Verification

- Composer metadata, PHP syntax, WPCS/PHPCompatibility, PHPStan and strict line
  budget pass.
- PHPUnit: 40 tests and 128 assertions.
- Vitest: 14 tests.
- WordPress integration: all kernel, admin, Entry, Collection and bridge scripts
  pass; the V0.9 bridge script contributes 32 assertions.
- Collection performance: 10,000 indexed CCT rows, p95 30.80 ms and at most
  three queries in the local runtime.
- Legacy Filter Controller regression: 113 passes, zero failures and 14 explicit
  human visual-QA gates.
- Playwright: eight wp-admin, Elementor and frontend scenarios pass with the
  existing accessibility checks.
- Generated assets and Git whitespace checks pass.
